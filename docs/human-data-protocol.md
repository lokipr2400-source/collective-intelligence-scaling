# Human Data Protocol

## Current Status
All examples, synthetic datasets, and demonstration scripts in this repository use non-human (synthetic or simulated) data only.

## Requirements Before Collecting Human Data
1. Written informed consent from every participant.
2. Data minimization: collect only attributes required for the diversity and density metrics.
3. Right to withdraw: participants may request deletion of their contributions at any time.
4. No raw personal identifiers stored with preference pairs.

## Template Consent Statement
"I understand this is an experimental collective-intelligence scoring exercise. My responses will be used only to compute diversity and information-density metrics. I may withdraw at any time."

## Trial Ladder
1. Synthetic only (current).
2. Opt-in internal team of ≤ 10 people with written consent.
3. External pilot only after stages 1 and 2 results are published.
