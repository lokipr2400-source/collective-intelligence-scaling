# Contributing

Thank you for your interest in this repository.

## Current Status
This is a research prototype. All examples and the synthetic dataset use non-human data only.

## Preferred Contributions
- Synthetic data that follows the schema in `docs/measurement-protocol.md`
- Improvements to the diversity or information-density proxies
- Unit tests or documentation clarifications
- Security or deployment hardening

## Human Data
Any contribution involving real participant data must follow the requirements in `docs/human-data-protocol.md`. Pull requests that include human data without clear consent documentation will be declined.

## Pull Request Guidelines
- Include a short note describing which metric (D or I_d) or tool is affected
- Run the unit tests in `tests/` before submitting
- Keep changes focused

Questions or proposals can be opened as issues.
